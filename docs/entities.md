# Entidades Principais (Glossário)

Dicionário de termos técnicos e entidades do banco de dados do ArenaHub.

| Entidade | Descrição |
| :--- | :--- |
| **Company (Tenant)** | A conta mestra da empresa que assina o SaaS. |
| **SaaSSubscription** | O vínculo da Company com um plano do ArenaHub. |
| **Arena** | Unidade física (ex: "Arena Centro", "Arena Praia"). |
| **Court (Quadra)** | O recurso específico que é alugado (ex: "Quadra 1 - Areia"). |
| **StaffUser** | Usuário que trabalha na arena (Admin ou Staff). |
| **Customer** | O cliente final ou aluno. |
| **Booking** | Uma reserva avulsa (única). |
| **Membership** | O contrato de um mensalista (recorrência). |
| **Class** | Uma turma de aula com horário fixo e capacidade. |
| **Enrollment** | A matrícula de um Customer em uma Class. |
| **Payment** | Registro financeiro de uma transação. |
| **ManualBlock** | Bloqueio administrativo de horário na agenda. |
