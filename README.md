# ArenaHub - Gestão de Arenas Esportivas

Bem-vindo ao **ArenaHub**, o SaaS definitivo para gerenciamento de quadras e arenas.

## 🚀 Visão Geral
O ArenaHub permite que donos de arenas gerenciem agendas complexas (reservas, mensalistas e aulas) enquanto oferecem uma interface simples de reserva online para seus clientes.

## 🛠️ Módulos em Destaque (MVP)
- **Agenda Inteligente**: Detecção de conflitos em tempo real.
- **Página Pública**: Sua arena aberta para reservas 24/7.
- **Mensalistas e Aulas**: Controle de recorrência e capacidade.
- **Gestão Financeira**: Controle de quem pagou e quem está pendente.
